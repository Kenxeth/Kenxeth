## 🚀 What I've Been Building

### ⚡ EventFlow — Serverless Event Processing Pipeline

An event-driven backend built to explore how scalable cloud systems process data asynchronously.

```text
Client
  │
  ▼
API Gateway
  │
  ▼
Lambda
  │
  ▼
SQS ────────► DLQ
  │
  ▼
Lambda Worker
  │
  ├────────► DynamoDB
  │
  └────────► S3
```

**Built with**

`AWS Lambda` · `API Gateway` · `SQS` · `DynamoDB` · `S3` · `CloudWatch` · `Terraform` · `TypeScript`

> ⚡ Load tested with **10,000+ events** while experimenting with retries, dead-letter queues, idempotency, and serverless architecture.
